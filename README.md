# AI-Quota-Float
Help users visualize their remaining token quota and usage more intuitively.

## Download

请从右侧 Releases 下载正式可运行版本：

`AI-Quota-Float-v0.1.0-win-x64.zip`

不要使用 `Code -> Download ZIP` 作为安装包，因为仓库源码包不包含完整 Electron 运行文件。

## Usage

1. 下载 Release 里的 zip
2. 解压整个压缩包
3. 双击运行 `AI-Quota-Float.exe`

## API Key

发布包不包含任何 API Key。每个用户首次打开后，在设置中填写自己的 API Key。Key 会加密保存在用户自己的电脑本地。
